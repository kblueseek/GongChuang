# 树莓派项目构建指南

目标平台：树莓派（推荐 4B/5）+ **Ubuntu 26.04** + **ROS2 Lyrical Luth**（Ubuntu 26.04 对应的 LTS 发行版）。

本文从零讲清：硬件接线 → 系统/ROS2 → 串口 → YDLIDAR 驱动 → 构建 → 运行 → 联调顺序 → 排错。

---

## 0. 角色与数据流

树莓派是决策层，F407 是执行层：

- 树莓派**只下发目标**（速度 / 云台角度 / 舵机 / 使能），电机 PID 闭环在 F407 上 20kHz 完成；
- F407 通过遥测回传里程计 `0x81` 和整车状态 `0x83`；
- 树莓派串口与 F407 USART6（PC6/PC7，115200 8N1）直连，两端均为 **3.3V TTL**，共地即可，无需电平转换。

```
激光雷达 ──/scan──> obstacle_detect ──/obstacles──> motion_planner ──/cmd_vel──┐
                                                                              v
USB摄像头 ──> vision（独立进程，旧协议，待迁移）                          f407_bridge ──PiComm(AA 55)──> F407 USART6
                                                                              ^
                                                     /odom /robot_status <────┘
```

## 1. 硬件接线

| 信号 | F407（USART6） | 树莓派 GPIO | 备注 |
|------|---------------|-------------|------|
| TX   | PC6            | RXD（GPIO15，UART0_RX） | 交叉连接 |
| RX   | PC7            | TXD（GPIO14，UART0_TX） | 交叉连接 |
| GND  | GND            | GND         | 必须共地 |
| 激光雷达 | ——            | USB 口     | YDLIDAR X3 PRO 自带 USB 转串口 |

> 接线图参考仓库根目录 `docs/树莓派拓展版接线.png`。

## 2. 系统与 ROS2

1. 烧录 Ubuntu 26.04（Server 或 Desktop 均可；视觉需要图形环境，用 Desktop 更省事）。
2. 安装 ROS2 Lyrical Luth 桌面版，官方步骤（把页面里的发行版换成 `lyrical`）：
   <https://docs.ros.org/en/rolling/Installation/Ubuntu-Install-Debs.html>
3. 验证：
   ```bash
   source /opt/ros/lyrical/setup.bash
   ros2 --help
   ```

## 3. 串口（Pi ↔ F407）

Ubuntu 下在 `config.txt`（`/boot/firmware/config.txt` 或 `/boot/config.txt`）追加：

```
enable_uart=1
dtoverlay=disable-bt      # Pi 3/4 释放与蓝牙复用的 UART；Pi 5 可省略
```

重启后串口映射到 `/dev/serial0`（通常是 `/dev/ttyAMA0`）。验证：

```bash
ls -l /dev/serial0 /dev/ttyAMA0
```

> 首次联调可先脱离 ROS2 单独验证串口 + 协议，见 §6。

## 4. YDLIDAR X3 PRO 驱动

1. 建 udev 规则，把激光雷达固定成 `/dev/ydlidar`（脚本已生成，这里列出内容）：
   ```bash
   sudo tee /etc/udev/rules.d/ydlidar.rules >/dev/null <<'EOF'
   KERNEL=="ttyUSB*", ATTRS{idVendor}=="10c4", ATTRS{idProduct}=="ea60", MODE:="0666", SYMLINK+="ydlidar"
   EOF
   sudo udevadm control --reload-rules && sudo udevadm trigger
   ```
   > 若 `lsusb` 显示的 VID/PID 不是 `10c4:ea60`，据实修改。X3 PRO 用 CP2102 串口芯片。

2. 拉取并构建官方驱动（含 YDLidar-SDK 子模块）：
   ```bash
   cd ~/GongChuang/树莓派/ros2_ws/src
   git clone --recursive https://github.com/YDLIDAR/ydlidar_ros2_driver.git
   ```
   驱动参数见 [lidar_bringup/config/x3_pro.yaml](../ros2_ws/src/lidar_bringup/config/x3_pro.yaml)。

```bash
source /opt/ros/lyrical/setup.bash

ros2 launch lidar_bringup x3_pro.launch.py    # 只起雷达，先确认有 /scan
```

常用检查：

```bash
ros2 topic list

ros2 topic echo /obstacles              # [front, left, right, back] 米
ros2 topic echo /odom
ros2 topic echo /robot_status
```

## 6. 联调顺序（强烈建议按序）

不要一上来就发速度。按下面顺序逐步验证：

1. **心跳 / 状态**：先跑 `comm/pi_comm.py` 自检脚本，确认能收到 `0x83` 状态帧：
   ```bash
   python3 comm/pi_comm.py /dev/serial0
   ```
   收到 `状态: (state, err, motor_mask)` 且 `motor_mask == 0x7F`（7 个电机全在线）再继续。

2. **里程计**：推动小车，`/odom` 的 x/y/theta 应随之变化（单位/方向核对）。

3. **使能**：`ros2 topic pub /cmd_enable std_msgs/msg/Bool "data: true"`，F407 进入 `ROBOT_READY`。

4. **低速前进**：
   ```bash
   ros2 topic pub /cmd_vel geometry_msgs/msg/Twist \
     "{linear: {x: 0.1, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.0}}"
   ```

5. **急停**：任何异常立即 `ros2 topic pub /cmd_estop std_msgs/msg/Bool "data: true"`。

## 7. 单位与坐标系约定

- PiComm 速度帧：vx/vy 单位 **mm/s**，wz 单位 **mrad/s**（`encode_vel` 负责从 m/s、rad/s 换算）；
- 里程计帧：x/y 单位 **mm**，theta 单位 **mrad**（`parse_odom` 换算成 m、rad 后发 `/odom`）；
- 舵机角度 0~180°；
- `/obstacles`：`[front, left, right, back]`，单位米，`left` 为车辆左侧（90°），`right` 为 270°。

## 9. 常见问题

| 现象 | 排查 |
|------|------|
| `/scan` 无数据 | `ls -l /dev/ydlidar`；驱动是否 build 成功；USB 供电是否足够（换带供电的 USB HUB） |
| 串口收不到帧 | 检查 TX/RX 是否交叉、是否共地；`config.txt` 是否 `enable_uart=1`；波特率是否 115200 |
| `motor_mask != 0x7F` | 对应电机离线或 CAN 未上电，查 F407 侧 CAN/电机电源 |
| 收到帧但 CRC 错 | 波特率不匹配、线材过长、或两边协议版本不一致——**逐字节核对 PiComm.c** |
| colcon build 失败 | 确认已 source ROS2；`python3-colcon-common-extensions` 已装 |
