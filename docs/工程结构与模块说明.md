## 一、代码规范（沿用 RM 项目）

1. **总头文件 header.h**：每个 `.c` 开头 `#include "header.h"`。header.h 无 include 保护，**任何 .h 里禁止包含 header.h**（防止递归）。
2. **命名**：模块前缀 + 动词（`ZdtMotor_SetSpeed`、`Servo_SetAngle`）；类型后缀 `_t`（`Chassis_t`）；模块内静态变量 `s_` 前缀（`s_RxCnt`）。
3. **全局实例**：每个模块一个全局结构体（`Chassis_t Chassis`），`.h` 里 `extern`，`.c` 里定义。任务间靠它共享数据，不设全局散变量。
4. **任务写法**：任务开头初始化自己的模块（电机注册、PID 初始化），循环用 `osDelayUntil(&PreviousWakeTime, TICK)` 固定周期。任务周期宏定义在各自 .c 顶部。
5. **配置集中**：所有可调参数进 `RobotConfig.h`，代码里不出现裸数字。

## 二、模块与数据流

```
树莓派 ──USART1──> PiComm(中断解析) ──PiCommand──> ReceiveTask(状态/心跳)
蓝牙   ──USART2──> BleControl ────(树莓派掉线时接管)───> PiCommand
                                                       │
                            ┌──────────────────────────┼─────────────────────┐
                            ▼                          ▼                     ▼
                     ChassisTask                  GimbalTask             DebugTask
                     (麦轮解算)                   (三轴位置)             (数据回传)
                            │                          │                     │
                            ▼                          ▼                     ▼
                     ZdtMotor.SetSpeed          ZdtMotor.SetPosition     USART6 DMA
                            │                          │                → 上位机
                            └──────────┬───────────────┘
                                       ▼
                              ZdtMotor.c ──CAN1──> 7 个 ZDT 电机
                             (电机返回) ──> ZdtCan_RxCallback 更新 Real/Status

JY901S ──USART3──> JY901S(中断解析) ──JY901S──> ImuTask ──Imu──> 各任务
```

### 全局结构体一览

| 结构体 | 定义处 | 内容 |
|---|---|---|
| `PiCommand_t PiCommand` | PiComm.c | 树莓派指令：Vel{Vx,Vy,Wz}、GimbalTarget[3]、舵机角度、EnableMask、Estop |
| `Chassis_t Chassis` | ChassisTask.c | 4 轮 ZdtMotor_t + Move 速度 + 载物盘 Servo_t |
| `Gimbal_t Gimbal` | GimbalTask.c | 三轴 ZdtMotor_t + 夹爪/摄像头 Servo_t |
| `Imu_t Imu` | ImuTask.c | Yaw/Pitch/Roll + Gyro/Acc + 速度估计(TODO) |
| `Receive_t Receive` | ReceiveTask.c | 整车状态机 + ErrorFlag |
| `JY901S_t JY901S` | JY901S.c | 模块原始数据（供 ImuTask 取用） |
| `BLE_Remote_t BleRemote` | BleControl.c | 蓝牙遥控：摇杆/按键/滑杆缓存 + 在线时刻 |
| `DebugData_t DebugData` | DebugTask.c | Head + Value[12] + Tail |

## 三、树莓派协议速查（详见 PiComm.h）

帧：`AA 55 | LEN | SEQ | CMD | DATA | CRC16(MODBUS)`，LEN = CMD+DATA+CRC 字节数。

| CMD | 名称 | DATA | 频率 |
|---|---|---|---|
| 0x01 | 底盘速度 | vx vy wz（int16×3，mm/s、mrad/s） | 50Hz |
| 0x02 | 云台目标 | axis(0=yaw/1=lift/2=extend) + deg(int32×100) | 事件 |
| 0x03 | 云台回零 | mask(bit0-2) | 事件 |
| 0x04 | 夹爪舵机 | pos(0~180) | 事件 |
| 0x05 | 载物盘舵机 | pos(0~180) | 事件 |
| 0x06 | 摄像头舵机 | pos(0~180) | 事件 |
| 0x07 | 电机使能 | en + mask(bit0-6=电机1-7) | 事件 |
| 0x08 | 急停 | 无 | 事件 |
| 0x10 | 心跳 | 无 | 1Hz |

STM32 回传：0x81 里程计（TODO）、0x83 状态（state+err+电机在线掩码，10Hz）。

## 三·五、蓝牙遥控（类比 DBUS，USART2）

小程序数据包：`[joystick,Lx,Ly,Rx,Ry]`（摇杆）、`[key,n,down|up]`（按键）、`[slider,名称,值]`（滑杆 0~1）。

| 输入 | 映射 | 备注 |
|---|---|---|
| 摇杆 Ly | Vel.Vx（推上=前进） | 带死区 |
| 摇杆 Lx | Vel.Vy（左右平移） | |
| 摇杆 Rx | Vel.Wz（自转） | |
| key 1 | 使能 toggle（7 电机全开/全关） | 按下边沿 |
| key 2 | 急停（Estop + 清使能） | |
| key 3 | 解除急停 + 重新使能 | |
| slider servo1/2/3 | 夹爪 / 载物盘 / 摄像头舵机 0~180° | |
| slider yaw/lift/extend | 云台三轴目标（映射到软限位范围） | |

**优先级：树莓派 > 蓝牙**。树莓派在线时蓝牙输入只缓存不生效；树莓派掉线后蓝牙立即接管，双掉线则停车。这就是「没有树莓派也能验证控制功能」的开关。

## 四、ZDT 电机封装说明

- **电机内部闭环**（20kHz 位置/速度环），STM32 只下发指令，**不跑电机 PID**——这是和 RM 大疆电机（要跑电流环 PID）最大的区别。
- 注册表模式：`ZdtMotor_Init(&Chassis.Wheel[0], 1)` 注册进 `ZdtMotorList[8]`，CAN 中断里按地址自动回填 Real/Status。
- 底盘用**速度模式**（F6，周期重发兼心跳）；云台用**绝对位置模式**（FD，命令幂等可重发）。
- 上机前电机侧配置：通讯端口复用 = CAN(03)、地址 1-7、波特率 500K、应答方式 = None（见 Bring-up 清单）。

## 六、上电验证顺序（Bring-up）

1. 单独发 `ZdtCan_Enable(1, 1)`，确认电机 1 锁轴 → CAN 通
2. 蓝牙/串口助手发 `AA 55 05 00 07 01 01 4E 0D` 使能电机1 → 树莓派协议通
   （0x07 使能 en=1 mask=0x01，CRC 自行用工具算）
3. 发 CMD_VEL 前进指令，标定四轮方向系数
4. 发 CMD_GIMBAL_TARGET 验证三轴 + 软限位
5. 验证三个舵机角度
6. 断开树莓派，确认 500ms 后底盘自动停车（心跳保护）
