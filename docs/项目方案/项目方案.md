# 全向移动抓取机器人 项目方案

> 一句话概括：四轮麦克纳姆全向底盘 + 三轴云台 + 三舵机末端执行器；树莓派负责手柄输入与任务决策，STM32F407 负责实时运动控制，CAN 总线统一驱动 7 个闭环步进电机。

---

## 一、机械结构

### 1.1 总体构型

整机按 **底盘层 — 控制层 — 作业层** 三层布置，重心低、维护方便，各层之间用铜柱/铝型材连接，可整层拆装。

```
┌─────────────────────────────────────┐
│  作业层：三轴云台 + 夹爪 + 载物盘      │
├─────────────────────────────────────┤
│  控制层：F407 主控 / 树莓派 / 电源     │
├─────────────────────────────────────┤
│  底盘层：4 个麦克纳姆轮 + 4 个步进电机  │
└─────────────────────────────────────┘
        ○                      ○
        FL                     FR          ← 麦轮 X 型布局
                 ◎ 车头
        RL                     RR
        ○                      ○
```

### 1.2 底盘

| 项目 | 参数 / 方案 |
|---|---|
| 驱动方式 | 四轮麦克纳姆轮，**X 型布局**（辊子轴线与轮轴线成 45°） |
| 运动能力 | 前后、左右平移、原地自旋，以及任意方向的斜向平移（三自由度解耦） |
| 轮半径 | 39.25 mm（实测轮径 78.5 mm） |
| 轴距 / 轮距 | 300 mm × 300 mm（半轴距、半轮距均 150 mm） |
| 驱动电机 | 4 × ZDT Y42 闭环步进电机（Emm 固件，1.8° 步距角，16 细分 = 3200 脉冲/圈），驱动器内置编码器闭环 |
| 传动 | 电机轴直连轮毂，无减速箱，结构简单、无回程间隙 |

麦轮逆解算（车体系：x 前进、y 左移、ω 逆时针为正）：

```
v_FL = Vx - Vy - ω(Lx+Ly)        v_FR = Vx + Vy + ω(Lx+Ly)
v_RL = Vx + Vy - ω(Lx+Ly)        v_RR = Vx - Vy + ω(Lx+Ly)
```

### 1.3 作业机构

- **三轴云台**：Yaw 旋转轴、Lift 升降轴、Extend 伸缩轴，各由 1 个 ZDT 闭环步进电机驱动，均为**绝对位置模式**，可精确定位并保持。
- **末端执行器**：3 路 50 Hz 舵机
  - 夹爪舵机：物料抓取 / 释放
  - 载物盘舵机：物料转运与倾倒
  - 相机舵机：视觉相机俯仰，保证取景稳定

### 1.4 结构设计要点

1. **模块化**：底盘、云台、电控板均为独立模块，接口用同一套 CAN 总线与航空插头，便于快速维修。
2. **低重心**：电池与主控布置在底盘层中部，云台偏后，保证加速与急停时不倾覆。
3. **走线**：动力线与信号线分侧走线，CAN 差分线双绞，降低干扰。

### 2.3 通信链路

| 链路 | 方向 | 物理层 | 波特率/速率 | 内容 |
|---|---|---|---|---|
| 手柄 ↔ 树莓派 | 双向 | 蓝牙 2.4 G | — | 摇杆、按键 |
| 树莓派 → F407 | 单向上行 | 蓝牙（USART2） | 115200 | 速度指令、云台/舵机指令、使能、心跳 |
| F407 → 树莓派 | 单向下行 | LoRa（UART4） | 115200 / 空口 62.5 kbps | 里程计 20 Hz、状态 5 Hz |
| 树莓派 ↔ F407 | 双向 | USART6（有线备用） | 115200 | 同上下行，联调/比赛兜底 |
| F407 ↔ 电机 | 双向 | CAN1 | 500 kbps 扩展帧 | 速度/位置指令、编码器反馈 |
| F407 ↔ IMU | 单向 | USART3 | 115200 | 姿态角 |

> 上行与下行走两个不同物理通道（蓝牙 / LoRa），互不抢带宽；下行单帧最长 17 字节，实测占用空口带宽约 5%。

### 2.4 通信协议（PiComm）

自定义二进制帧，固定头 + 长度 + 序号 + 命令 + 数据 + CRC16：

```
┌────┬────┬─────┬─────┬─────┬──────────┬───────────┐
│ AA │ 55 │ LEN │ SEQ │ CMD │   DATA   │ CRC16(低高)│
└────┴────┴─────┴─────┴─────┴──────────┴───────────┘
 帧头(2)   长度(1) 序号(1) 命令(1)   N 字节    2 字节
```

- CRC16-MODBUS，覆盖「长度 ~ 数据」全部字节；
- 多字节数据统一大端；
- 接收端状态机逐字节重组，CRC 错、长度错直接丢帧，保证在无线链路上不误动作。

## 三、控制软件功能

### 3.1 软件分层

| 层 | 运行平台 | 主要功能 |
|---|---|---|
| 决策层 | 树莓派 / ROS2 | 手柄解析、动作序列状态机、状态显示、视觉识别（预留） |
| 实时控制层 | STM32F407 / FreeRTOS | 协议解析、底盘运动学、闭环控制、云台定位、安全保护 |
| 驱动层 | F407 + 电机驱动器 | CAN 帧收发、ZDT 协议封装、编码器反馈解析 |

### 3.2 STM32 端任务划分

| 任务 | 周期 | 优先级 | 职责 |
|---|---|---|---|
| `ImuTask` | 10 ms | High | 读取 JY901S，输出航向角 |
| `ReceiveTask` | 5 ms | AboveNormal | PiComm 解帧、CRC 校验、指令超时检测 |
| `ChassisTask` | 5 ms | Normal | 麦轮逆解算、位置闭环、航向 PID、CAN 下发 |
| `GimbalTask` | 20 ms | Normal | 云台三轴位置指令、三路舵机 PWM |

### 3.3 核心控制算法

1. **底盘运动学**：接收 `Vx / Vy / ω`，按麦轮逆解算得到四轮线速度，换算为 RPM 后通过 **CAN 多电机广播帧（0xAA）** 一次性下发，保证四轮严格同步启动。
2. **速度闭环**：由电机驱动器内置编码器闭环完成，主控只下发目标转速，降低主控负担。
3. **位置闭环**：读取四轮编码器计数积分得到里程计 (x, y)，与目标点比较，用位置 PID 修正 `Vx / Vy`。
4. **航向闭环**：IMU 航向角作为反馈，PID 输出作为自旋速度 `ω`，保持直线行驶不跑偏。
5. **云台定位**：绝对位置模式指令，支持上电回零与角度保持。

### 3.4 树莓派端节点

| 节点 | 功能 |
|---|---|
| `joy_control` | 读取手柄，映射为速度指令（含使能键、模式切换） |
| `f407_bridge` | PiComm 组帧/解帧，ROS2 话题 ↔ 串口/蓝牙转换 |
| `motion_planner` | 执行 JSON 动作序列（前进/平移/转向/抓取/延时），按里程计判断到位 |
| `status_display` | OLED 显示在线状态、里程计、使能状态、故障码 |

### 3.7 安全机制

1. **指令超时保护**：超过 500 ms 未收到树莓派指令（无线断链），自动速度清零并失能，防止失控。
2. **帧校验**：长度不符、CRC 错误、序号异常一律丢弃，不执行。
3. **电机在线检测**：电机超过 200 ms 无反馈即判离线，上报故障码并在屏幕上提示。
4. **双通道冗余**：无线链路异常时可切换到 USART6 有线链路，保证比赛现场可控。
5. **急停**：手柄失能键 / 上位机急停指令，立即将四轮速度置零。
