## 二、舵机（2 个，都是 180°）

TIM3 配成 50Hz / 20ms 周期（`Prescaler=83, Period=19999`，84MHz 定时器时钟），两个舵机挂在 TIM3 上：

| 引脚 | 功能 | 接什么 | 备注 |
|------|------|--------|------|
| PA6  | TIM3_CH1 | 舵机 1 信号（橙/白线） | 180° |
| PA7  | TIM3_CH2 | 舵机 2 信号（橙/白线） | 180° |

**舵机供电**：信号线接 3.3V 电平即可（舵机高电平阈值一般 2.0~2.4V）。**电源线（红）必须走独立 5~6V 轨**，不要从单片机 3.3V 取。两个舵机堵转电流可到 1~2A，电源板 XL4015 的 6V 轨对应接过来。用地平面共地。

> F407 的 TIM3 还有 CH3=PB0、CH4=PB1 可用，将来要加第三个舵机不用换定时器。

## 三、树莓派 / K230 / 补光灯

F407 有 **6 个串口**（USART1/2/3/6 + UART4/5），比 F103 的 3 个宽裕得多，不再有「串口不够用」的问题：

| 引脚 | 功能 | 接什么 | 备注 |
|------|------|--------|------|
| PB10 | USART3_TX | 树莓派 RX | 已占用 |
| PB11 | USART3_RX | 树莓派 TX | 已占用 |
| PC10 | UART4_TX | K230 RX（或备用） | 空闲可用 |
| PC11 | UART4_RX | K230 TX（或备用） | 空闲可用 |
| PC12 | UART5_TX | 备用 | 空闲可用 |
| PD2  | UART5_RX | 备用 | 空闲可用 |
| PA0  | TIM2_CH1   | 补光灯 PWM（调光） | 可选 |
| PA1  | TIM2_CH2   | 预留 | |

**K230 和树莓派怎么接？**
现在串口够用，可以 **STM32 直连 K230（UART4）**，也可以维持「K230 → 树莓派 → STM32」的拓扑。直连更简单，各占一个串口互不干扰。

**补光灯**：只做开关就用任意 GPIO 驱动 NMOS（如 AO3400）拉低灯珠负极；要做调光就走 TIM2_CH1（PA0）。

## 五、F407VET6 引脚资源总览（LQFP100）

F407 引脚多，不再逐个列 100 脚，按**外设分组**给出可用资源，方便 PCB 排布：

| 外设 | 可用引脚 | 本项目用途 |
|------|---------|-----------|
| USART1 | PA9/PA10、PB6/PB7 | **电机总线**（PA9/PA10） |
| USART2 | PA2/PA3、PD5/PD6 | **蓝牙**（PA2/PA3） |
| USART3 | PB10/PB11、PC10/PC11、PD8/PD9 | **树莓派**（PB10/PB11） |
| UART4 | PA0/PA1、PC10/PC11 | 空闲（K230 候选） |
| UART5 | PC12/PD2 | 空闲 |
| USART6 | PC6/PC7、PA11/PA12 | 空闲（注意 PA11/12 复用 USB） |
| TIM3 CH1~CH4 | PA6/PA7/PB0/PB1 | **舵机 1/2**（PA6/PA7），CH3/4 预留 |
| TIM2 CH1~CH4 | PA0/PA1/PA2/PA3 等 | 补光灯 PWM（PA0） |
| CAN1 | PA11/PA12、PB8/PB9、PD0/PD1 | 弃用 |
| I2C1 | PB6/PB7、PB8/PB9 | 空闲（陀螺仪等候选） |
| SPI1 | PA5/PA6/PA7 等 | 空闲（注意 PA6/PA7 已被舵机占） |
| ADC | PA0~PA7、PB0/PB1、PC0~PC5 | 空闲（电池电压检测等） |

**GPIO 分组速记**：PA0~PA15、PB0~PB15、PC0~PC15、PD0~PD15 全部可用；PE 口在 LQFP100 上只有 PE0~PE6。核心外设（串口×6、定时器×14、I2C×3、SPI×3、CAN×2、USB OTG FS、SDIO、FSMC）都能完整引出。

## 六、支撑电路（最小系统板已内置，不用另画）

用**最小系统板 / 核心板**时，下面这些电路板子上全都有：复位、BOOT0/BOOT1 选择、8MHz 主晶振、3.3V 稳压、电源去耦、VDDA/VBAT 处理、SWD 下载排针（PA13/PA14）。

你只需画**载板 / 转接板**：把上面「接口总表」里的排针引到各外设，并处理好**电源轨和共地**。

> 自画 MCU 板才需要的清单（用最小系统板可忽略）：
> - 复位：NRST 经 10k 上拉到 3.3V，对地接 100nF + 复位按键
> - BOOT0：10k 下拉到 GND，串跳线帽可拉高（进 ISP）
> - 晶振：8MHz 无源晶振 + 2×20pF 到 GND，贴近 PH0/PH1
> - 电源去耦：每个 VDD 一个 100nF；整板并 10µF
> - 下载口：4 pin 排针 3.3V / GND / SWDIO(PA13) / SWCLK(PA14)

## 七、PCB 布局 / 走线注意

1. **电机总线是共用总线**：STM32 的 PA9(TX) 并联到 **7 个电机 RX**；7 个电机 TX 全部并联回 PA10(RX)。PA10 输入端串 **100Ω** 保护。
   - 这是「半双工」总线：**同一时刻只能一个电机说话**。别让多个电机同时开「定时返回」，否则数据撞车。
2. **总线长度**：超过 1 米用双绞的 GND 跟信号线配对走，减少干扰。GND 必须和电机驱动器共地。
3. **电机线不要和晶振走线并排**：8MHz 晶振区域最敏感，底下铺地、周围包地。
4. **舵机轨和逻辑电源分开**：舵机 5~6V 轨和单片机 3.3V 轨在电源板上分开走线，入口单点汇合（星形接地）。
5. **大电流路径**：电机/舵机供电走线按 **1A/mm（1oz 铜，温升 10℃）** 估算，24V 母线峰值 ~14A，主线 ≥ 4mm 或直接铺铜。
