## 一、电机串口总线（UART5，本次重点）

### 1.1 接线（TTL 多机并联）

STM32 的 UART5 是 3.3V TTL 电平，直接并联即可，**无需收发器**：

```
STM32 PC12 (TX) ──────────┬──────────┬──────────┬──────────┬ ...
                          │          │          │          │
                      电机1.RX    电机2.RX    电机3.RX    电机4.RX
STM32 PD2 (RX) ──────────┼──────────┼──────────┼──────────┼ ...
                          │          │          │          │
                      电机1.TX    电机2.TX    电机3.TX    电机4.TX
GND ─────────────────────┴──────────┴──────────┴──────────┴ ...
```

- **TX 一对多、RX 多对一并线**，所有电机 TX 并联到 PD2。
- **必须共地**。
- 波特率 **115200 / 8N1**，校验固定 **0x6B**。
- 主从问答式：同一时刻只有一个电机回话，短距离 TTL 直连可用；走长线建议改 RS485。

### 1.2 电机地址表（串口帧首字节 = 地址）

| 地址 | 电机 | 角色 | 控制模式 | 固件 |
|---|---|---|---|---|
| 1 | 底盘 前左 FL | 麦轮 | 速度模式（F6） | Emm |
| 2 | 底盘 前右 FR | 麦轮 | 速度模式（F6） | Emm |
| 3 | 底盘 后左 RL | 麦轮 | 速度模式（F6） | Emm |
| 4 | 底盘 后右 RR | 麦轮 | 速度模式（F6） | Emm |
| 5 | 云台 Yaw | 旋转轴 | 绝对位置模式（FD） | Emm |
| 6 | 云台 Lift | 升降轴 | 绝对位置模式（FD） | Emm |
| 7 | 云台 Extend | 伸缩轴 | 绝对位置模式（FD） | Emm |

> ⚠️ **每台电机都要用上位机把「通讯端口复用」从 CAN 改成串口**，地址设成 1~7，波特率 115200，校验 0x6B。
> ⚠️ 固件是 **Emm**：速度命令 `F6 + 方向 + 速度(RPM) + 加速度档位`，位置命令 `FD`，与 X 固件格式不同，别抄错。

### 1.3 底盘多电机命令（0xAA）

底盘四个轮速用**多电机命令 0xAA** 打包成一帧下发（`00 AA 长度 + 四条子命令 + 6B`），四轮同步起步、只有地址 1 回 ACK，避免总线冲突和命令粘包。

| 引脚 | 通道 | 舵机 | 上电初始角 |

| PA7 | TIM3_CH2 | 载物盘 | 0° |

## 六、接线顺序建议（Bring-up）

1. 先接 **UART5 电机总线**：4 个底盘电机并联到 PC12/PD2，上位机把每台电机通讯端口切串口、设地址 1~4，串口助手发 `01 36 6B` 读位置验证。
2. 再接 **3 个舵机**，上电确认回中位。
3. 接 **树莓派（USART1）**，发 `CMD_VEL` 验底盘。
4. 接 **JY901S（USART3）**，先确认已改 115200。
5. 最后接 **蓝牙、调试口（USART2 / USART6）**。

## ⚠️ 容易踩的点

1. **晶振是 8MHz**：`.ioc` 配的是 HSE **8MHz**（PLLM=4 / PLLN=168 / PLLP=2）。接好前确认板载晶振确实是 8MHz，不是 25MHz，否则系统时钟不对。
2. **电机通讯模式**：每台电机默认/之前可能是 CAN 模式，必须用上位机切成**串口**并设对地址（1~7）、波特率 115200、校验 0x6B，否则对 UART 命令没反应。
3. **固件 Emm**：速度/位置命令格式和 X 固件不同（速度=整数RPM+档位加速度，位置=FD），抄协议时别用 X 固件的格式。
4. **JY901S**：USART3 按 115200 配，但模块出厂默认 9600，需先用上位机改成 115200 再接线。
