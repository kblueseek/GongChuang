## 二、建议新增：3 个舵机

TIM3 已经初始化成 50Hz / 20ms 周期（`Prescaler=71, Period=19999`），**四个通道共用同一个时基**，所以三个舵机全部挂在 TIM3 上最省事，一次配置四路都能用：

| 引脚 | 功能 | 接什么 | 备注 |
|------|------|--------|------|
| PA6  | TIM3_CH1 | 舵机 1 信号（橙/白线） | 已配置 |
| PA7  | TIM3_CH2 | 舵机 2 信号（橙/白线） | 已配置 |
| **PB0** | **TIM3_CH3** | **舵机 3 信号（橙/白线）** | ⚠️ 需改配置，见下 |
| PB1  | TIM3_CH4 | 预留（舵机 4 / 补光灯） | 可选 |

**PB0 注意**：当前 `.ioc` 里 PB0 被配成了「GPIO_Input 上拉」，而 TIM3_CH3 的默认复用引脚**正是 PB0**。代码里没有任何地方用到这个输入（我全局搜过），是 CubeMX 里留下的无用配置，直接改成 `TIM3_CH3` 即可，不会有任何损失。

**如果不想动 PB0**：改用 TIM4 出三路 PWM（PB6/PB7/PB8/PB9 四个通道全空），代价是占用 I2C1 的 SCL/SDA 引脚，以后想加 I2C 传感器（如陀螺仪）就得再换。

**舵机供电**：信号线接 3.3V 电平即可（舵机高电平阈值一般 2.0~2.4V，3.3V 直驱没问题）。**电源线（红）必须走独立 5~6V 轨**，不要从单片机 3.3V 取，三个舵机堵转电流可到 2~3A。用地平面共地。电源板里已经规划了 XL4015 的 6V 舵机轨，对应接过来就行。

## 三、建议新增：树莓派 / K230 / 补光灯

STM32F103C8 一共只有 **3 个 USART**，现在的分配是：USART1=电机、USART2=蓝牙、**USART3 是唯一空着的**。

| 引脚 | 功能 | 接什么 | 备注 |
|------|------|--------|------|
| PB10 | USART3_TX | 树莓派 RX（或 K230 的 RX） | 115200 8N1 |
| PB11 | USART3_RX | 树莓派 TX（或 K230 的 TX） | |
| PA0  | TIM2_CH1  | 补光灯 PWM（调光） | 或普通 GPIO 做开关 |
| PA1  | TIM2_CH2  | 预留 | |

**K230 和树莓派抢串口怎么办？**
推荐拓扑：**K230 → 树莓派（USB 或独立串口）→ STM32（USART3）**。
K230 做视觉识别，结果本来就该给树莓派做决策，再由树莓派把运动指令下给 STM32，不需要 STM32 直连 K230。这样 USART3 一路给树莓派就够了。

如果你确实要 STM32 直连 K230，那要么放弃蓝牙（USART2 给 K230），要么用软件模拟串口（不推荐在 115200 下用）。

**补光灯**：只做开关就用任意 GPIO 驱动一个 NMOS（如 AO3400）拉低灯珠负极，栅极串 100Ω、加 10k 下拉；要做调光就走 PWM。12V 灯珠的供电由电源板的 12V 轨提供，注意 MOS 要选耐压 >30V 的。

## 六、支撑电路（最小系统板已内置，不用另画）

用**最小系统板**时，下面这些电路板子上全都有，**不用自己画**：复位、BOOT0/BOOT1 选择、8MHz 主晶振、3.3V 稳压（板载 AMS1117）、电源去耦、VDDA/VBAT 处理、SWD 下载排针（PA13/PA14）。

你只需画**载板 / 转接板**：把上面「接口总表」里的排针引到各外设，并处理好**电源轨和共地**。

> 下方清单是**自画 MCU 板**才需要的，用最小系统板可忽略，仅留作参考：

| 项目 | 接法 |
|------|------|
| 复位 | NRST 经 10k 上拉到 3.3V，对地接 100nF + 复位按键 |
| BOOT0 | 10k 下拉到 GND，串一个跳线帽可拉高（进 ISP 用）|
| 晶振 | 8MHz 无源晶振 + 2×20pF 到 GND，尽量贴近 PD0/PD1 |
| 电源去耦 | 每个 VDD 脚一个 100nF；整板再并一个 10µF |
| 模拟电源 | VDDA 经磁珠接 3.3V，配 100nF + 1µF；VSSA 单独接地 |
| VBAT | 接 3.3V（或留纽扣电池位 + 100nF）|
| 下载口 | 4 pin 排针：3.3V / GND / SWDIO(PA13) / SWCLK(PA14) |

## 七、PCB 布局 / 走线注意（针对本项目）

1. **电机总线是共用总线**：STM32 的 PA9(TX) 要并联接到 **7 个电机的 RX**；7 个电机的 TX 也全部并联回到 PA10(RX)。
   - 建议在 PA10 输入端串一个 **100Ω 电阻**做保护，防止某个电机异常拉低时把 IO 打坏。
   - 这是一条「半双工」总线：**同一时刻只能有一个电机在说话**。ST 的代码已经按这个前提写的（多机命令一次性下发 + 轮询单机读状态），别让多个电机同时开「定时返回」，否则数据会撞在一起。

2. **总线长度**：电机线如果超过 1 米，建议用双绞的 GND 跟信号线配对走，减少干扰。GND 一定要和电机驱动器共地。

3. **电机线不要和晶振走线并排**：8MHz 晶振区域是最敏感的，底下铺地、周围包地。

4. **舵机轨和逻辑电源分开**：舵机启停会造成很大的电流冲击，其 5~6V 轨和单片机 3.3V 轨在电源板上就要分开走线，最后在电源入口单点汇合（星形接地）。

5. **大电流路径**：电机/舵机供电走线宽度按 **1A/mm（1oz 铜，温升 10℃）**估算，24V 母线的峰值电流约 14A，主线建议 ≥ 4mm 或直接铺铜。
