## 一、电机 CAN 总线（CAN1，本次重点）

### 1.1 接线（CAN 多机并联）

CAN 是差分总线，**必须经过 CAN 收发器**（3.3V 逻辑 ↔ CAN_H/CAN_L），所有电机收发器并联在同一条总线上：

```
STM32 CAN1_TX (PB9) ──► 收发器.TXD
STM32 CAN1_RX (PB8) ◄── 收发器.RXD
收发器.CAN_H ─────────┬─────────┬─────────┬ ...（并到每个电机的 CAN_H）
收发器.CAN_L ─────────┼─────────┼─────────┼ ...（并到每个电机的 CAN_L）
GND ─────────────────┴─────────┴─────────┴ ...
```

- **CAN_H / CAN_L 全并联**，总线**两端各接一个 120Ω 终端电阻**（PCAN 端通常已带一个，另一端在电机总线末端补一个）。
- 波特率 **500K**，扩展帧，校验固定 **0x6B**。
- 多机靠**扩展帧 ID 区分地址**，全双工差分，不需要像串口那样分时问答。

### 1.2 电机地址表（CAN 扩展帧 ID = 地址<<8 | 包序号）

| 地址 | 电机 | 角色 | 控制模式 | 固件 |
|---|---|---|---|---|
| 1 | 底盘 前左 FL | 麦轮 | 速度模式（F6） | Emm |
| 2 | 底盘 前右 FR | 麦轮 | 速度模式（F6） | Emm |
| 3 | 底盘 后左 RL | 麦轮 | 速度模式（F6） | Emm |
| 4 | 底盘 后右 RR | 麦轮 | 速度模式（F6） | Emm |
| 5 | 云台 Yaw | 旋转轴 | 绝对位置模式（FD） | Emm |
| 6 | 云台 Lift | 升降轴 | 绝对位置模式（FD） | Emm |
| 7 | 云台 Extend | 伸缩轴 | 绝对位置模式（FD） | Emm |

> ⚠️ **每台电机都要用上位机把「通讯端口复用」设成 CAN(03)**，地址设成 1~7，波特率 500K，校验 0x6B。
> ⚠️ 固件是 **Emm**：速度命令 `F6 + 方向 + 速度(RPM) + 加速度档位 + 同步标志`，位置命令 `FD`，与 X 固件格式不同。

### 1.3 底盘多电机命令（0xAA）

底盘四个轮速用**多电机命令 0xAA** 打包成一条广播帧下发（`00 AA 长度 + 四条子命令 + 6B`，CAN 上按包序拆成扩展帧 ID `0000/0001/...`），四轮同步起步、只有地址 1 回 ACK，避免总线冲突。

### 1.4 编码器反馈（定时返回 0x36）

每台底盘电机配置了「定时返回实时位置 0x36」，每 `ZDT_FEEDBACK_PERIOD_MS`（默认 5ms）主动上报一次编码器位置（多圈累计，65536 计数 = 一圈），STM32 用整数计数差分积分成里程计，供回零位置闭环使用。

## 六、接线顺序建议（Bring-up）

1. 先接 **CAN 电机总线**：接好 CAN 收发器，把 4 个底盘电机（+收发器）并联到 CAN_H/CAN_L，上位机把每台电机通讯端口切 CAN、设地址 1~4，PCAN/串口助手发 `01 36 6B` 读位置验证。
2. 再接 **3 个舵机**，上电确认回中位。
3. 接 **树莓派（USART6）**，发 `CMD_VEL` 验底盘。
4. 接 **JY901S（USART3）**，先确认已改 115200。
5. 最后接 **蓝牙（USART2）、调试口（USART1）**。

## ⚠️ 容易踩的点

1. **晶振是 8MHz**：`.ioc` 配的是 HSE **8MHz**（PLLM=4 / PLLN=168 / PLLP=2）。接好前确认板载晶振确实是 8MHz，不是 25MHz，否则系统时钟不对。
2. **电机通讯模式**：每台电机默认/之前可能是串口模式，必须用上位机切成 **CAN** 并设对地址（1~7）、波特率 500K、校验 0x6B，否则对 CAN 命令没反应。
3. **CAN 收发器必接**：CAN 是差分信号，ST 的 PB8/PB9 是逻辑电平，不接收发器直接并线读不到也发不出。
4. **终端电阻**：总线两端各 120Ω，少了长线会反射、通讯不稳。
5. **固件 Emm**：速度/位置命令格式和 X 固件不同（速度=整数RPM+档位加速度，位置=FD），抄协议时别用 X 固件的格式。
6. **JY901S**：USART3 按 115200 配，但模块出厂默认 9600，需先用上位机改成 115200 再接线。
