# 24V 电源保护板设计说明

> 输入：24V 电池；输出：7×Y42 步进电机（母线直连）、3×舵机（6V）、1×K230（5V）、1×补光灯（12V）；树莓派用自带稳压板（独立路径，不经过本板）。

---

## 1. 功耗预算（24V）

| 外设 | 数量 | 供电 | 典型电流 | 峰值电流 |
|---|---|---|---|---|
| Y42 步进电机 | 7 | 24V 母线直连 | 1~1.5A/个 | 3A/个 |
| 舵机 | 3 | 6V(Buck) | 0.5A/个 | 2A/个(堵转) |
| K230 摄像头 | 1 | 5V(Buck) | 0.6A | 1A |
| 补光灯 | 1 | 12V(Buck 或直连) | 0.5A | 1A |
| 树莓派 | 1 | 自带板(独立) | ~1A@24V | ~1.3A@24V |

**母线（步进电机这路）**：7 个电机**不会同时全速/全堵转**——按「底盘 4 轮同时驱动 + 机械臂 1 轴动作」估算，典型 **~5.5A**、峰值 **~14A**。理论最坏（7 个全堵转）为 3A×7 = **21A**。主保险丝按 15A 选是以「不出现 7 电机同时满功率」为前提；若机械臂三轴会同时重载，保险丝与母线走线需上调到 20A 以上。
降压路折算到 24V 输入侧都 ≤1.5A，对母线影响小。

> ⚠️ 先确认电池类型定耐压：6S 锂离子满电 25.2V；24V 铅酸/8S 磷酸铁锂满电可达 28~29V。以下器件按 24V 标称选型，输入侧电容用 50V 有足够余量。树莓派稳压板需确认输入确实能吃 24V。

## 3. 芯片选型表

| 位置 | 需求 | 推荐芯片 | 关键参数 |
|---|---|---|---|
| 反接保护 | 母线入口 | P-MOS `IRF4905` / `AOD4185` / `SUP75P03` | ≥24V、≥20A、Rds(on)≤20mΩ |
| 过压瞬态 | 母线入口 | TVS `SMCJ30A` | 30V 反向截止、钳位 ~48V、1500W |
| 防打火 | 母线入口 | NTC `MF72-5D9` | 5Ω，限制上电充电电流 |
| 主保险丝 | 母线 | 车用插片保险丝 / 自恢复 PTC | 15A |
| 舵机 Buck | 24V→6V，≥5A | **`XL4015`** 或 `TPS5450` | 5A / 8~36V 输入 |
| K230 Buck | 24V→5V，2~3A | **`LM2596HV`** / `TPS5430` | 3A / 4.5~60V 输入 |
| 补光灯 | 24V→12V（若 12V LED） | `XL4015` / `LM2596HV` | 若直接买 24V LED 则省去 |

**选型理由**：三个降压需求用两颗芯片即可覆盖——`XL4015`(5A) + `LM2596HV`(3A)，都是宽压输入、便宜、参考设计多、立创商城常备。

> 注：`MP1584` 虽常用但绝对上限 28V，接 24V 铅酸/8S 磷酸铁锂满电（28~29V）太贴线，不建议；用 `LM2596HV`(60V) 最稳。

## 4. 各模块设计要点

### 4.1 输入保护（两路都要）

- **反接保护**：P-MOS 电路（S 接电池、D 接负载、G 经电阻接地），比二极管好——大电流不发热、无压降损耗。MOS 选 ≥30V、≥20A。
- **TVS**：`SMCJ30A` 并接在母线正负极之间，吸收步进电机反电动势尖峰和插拔瞬态。**不能省**。
- **防打火 NTC**：母线有大电解电容，直接插电池会打火。串 5Ω NTC 限流，上电后随电流发热阻值下降。
- **主保险丝**：15A；树莓派独立路径另串 5A 保险丝。

### 4.2 电机母线（7×步进，24V 直连）

- 7 个步进电机直接吃 24V 母线（手册 10~29V 内）。
- **分组加保险丝**：底盘 4 个一组、机械臂 3 个一组，各串自恢复 PTC 或小插片保险丝，防止单电机短路烧整板。
- 母线并 **1000~2200μF/50V 电解 + 100nF 陶瓷**，靠近电机供电端子再各放 100μF。
- 这是最大噪声源，走线加粗、独立地平面。

### 4.3 舵机 Buck（24V→6V，XL4015）

- 3 舵机同时堵转理论 6A，`XL4015` 标称 5A：靠 **2200μF 输出电容**扛短时尖峰 + 串保险丝；真不放心就舵机分两路各一颗。
- 典型外围：输入 220μF/35V + 100nF；输出 2200μF/16V + 100nF；电感 47μH(≥5A 饱和)；续流二极管 `SS54`(5A/40V)。
- 输出 6V：反馈电阻按 `Vout = 1.25V×(1+R上/R下)` 配（**XL4015 基准是 1.25V**，不是 0.8V），取 R上/R下 ≈ 3.8（如 R上=39kΩ、R下=10kΩ 得 ~6.1V，或 R上=10kΩ、R下=2.7kΩ 得 ~5.9V）。

### 4.4 K230 Buck（24V→5V，LM2596HV）

- 5V/2~3A 足够（K230 典型 3~5W）。
- 典型外围：输入 100μF/35V；输出 470μF/10V；电感 33μH；续流 `SS34`(3A/40V)。
- **务必独立、干净**：入口加 LC/磁珠滤波，与电机地单点接地——摄像头对电源噪声敏感。

### 4.5 补光灯

- 12V LED：加一路 24V→12V Buck（`XL4015`/`LM2596HV`）+ MOSFET 开关（树莓派/STM32 的 PWM 调光）。
- 直接买 24V LED 灯条则省掉这路，母线 + MOSFET 直驱。

### 4.6 地线与隔离

- 电机是强噪声源，**电机地与数字地（K230/树莓派/STM32）单点星型接地**。
- 数字电源入口加磁珠/LC，STM32 板供电从干净 5V/3.3V 取，**别从电机母线直接取**。

## 6. PCB 走线注意事项

1. **母线大电流走线**：峰值 14A，主路径铜宽 ≥3~4mm（1oz）或加锡/2oz；电机供电用螺丝端子或 XT60。
2. **Buck 开关环路最小化**：输入电容 → 芯片 → 续流二极管 → 电感 → 输出电容 这个环路面积越小越好，是 EMI 和纹波的关键。
3. **地平面**：整板铺地，电机地、数字地分区后再单点相连。
4. **散热**：Buck 芯片底部铺铜 + 打散热过孔；满载 5A 的 XL4015 建议加小散热片。
5. **反馈采样点**：Buck 反馈电阻的采样点尽量靠近负载端，减小走线压降导致的输出偏差。
6. **端子区分**：母线、6V、5V、12V 用不同颜色/标签，防止误插烧板。

## 7. 开源参考（按推荐顺序）

1. **立创开源广场 oshwhub.com**：搜「电源管理板」「24V 降压」「电源分配板 PDB」，可直接打板、带 BOM。
2. **DJI RoboMaster 电源管理模块 / 开发板原理图**：公开的「24V 输入 → 多路降压 + 保护 + 电流采样」，形态与本板几乎一致，GitHub 搜 `RoboMaster power management`。
3. **芯片 datasheet 典型应用电路**：`TPS5450`、`XL4015`、`LM2596HV` 的 datasheet 里有现成参考电路，照抄即可。
4. GitHub 搜 `power distribution board robot` / `robot PDB`（FRC、RoboMaster 队公开设计）。
