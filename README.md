# 物流搬运智能车 — 电控代码

基于 **STM32F103C8T6**（运动控制）+ **树莓派 ROS2**（决策感知）+ **7× ZDT Y42 闭环步进电机** 的物流搬运智能车电控工程。

## 系统构成

- **底盘**：4× Y42 麦轮（Emm 固件，速度模式）
- **三轴臂**：3× Y42（Yaw 旋转 / 上下升降 / 左右伸缩，Emm 固件，位置模式）
- **夹爪**：1× 舵机（PWM 开合）
- **通讯**：一条 UART 总线挂 7 个电机（TX-only，多电机命令打包）
